# 数据集说明（Data not included）

出于隐私与授权原因，本仓库**不包含**任何说话人音频、视频、切片、特征或模型权重。

要复现实验，请准备**你本人或已获得明确授权**的单人干声数据，并自行完成清洗与审计。

## 1. 推荐素材标准

| 要求 | 说明 |
|---|---|
| 单人 | 只包含目标说话人，无其他人声/和声 |
| 干声 | 无伴奏、无 BGM、无混响/回声；安静环境 |
| 时长 | 10–30 分钟有效人声（研究显示更多数据对 s2 有益，但要先保证质量） |
| 内容 | 唱歌音色用清唱/干声演唱；说话音色用朗读/自然说话 |
| 格式 | wav / mp3 / m4a / mp4 / flac 等均可，后续统一转 48 kHz 单声道 |

## 2. 建议的目录布局

```text
data/
├── raw/                 # 原始媒体（不提交）
├── clips/               # 切片（不提交）
└── features/            # HuBERT / BERT / 语义特征（不提交）
```

## 3. 清洗与审计流程

1. 抽取音轨：`scripts/extract_clean.py` / `dedupe_extract.py`（48 kHz 单声道、SHA-1 去重）；
2. 质量审计：`scripts/audit_large_dataset.py`（响度、削波、静音、低频能量、频谱质心）；
3. 过滤：`scripts/filter_quality.py`（剔除 vlog/非歌唱、过轻、静音、疑似伴奏）；
4. 可视化：`scripts/plot_quality.py`；
5. 切片与特征提取：按上游 RVC / GPT-SoVITS 的预处理脚本执行。

审计阈值参考：RMS > −25 dBFS、削波 < 0.5%、静音比例 < 45%、
低频能量比（<120 Hz）< 0.12、时长 ≥ 3 s。

## 4. 隐私提示

- 处理前请获得说话人书面授权；
- 数据集应加密保存、限制访问；
- 不要将原始音频、切片、特征、模型权重或含文件名的报告提交到公开仓库（`.gitignore` 已覆盖常见后缀）。
